# Maqto (ماكتو)

Free desktop video editor for Mac and Windows. Tauri 2 (Rust) + plain HTML/JS. Arabic and English UI.

- Timeline: main magnetic track, overlay video, text, captions, 2 audio tracks. Select/blade tools, split, delete left/right (Q/W), markers, snapping, undo.
- Clips: scale, position, opacity, crop, mirror, fades, speed, volume. Color: 8 filters + brightness/contrast/saturation/temperature (WebGL in preview, same math in ffmpeg).
- Text with motion (fade, slide, pop, typewriter). Arabic shaped by the webview.
- Arabic auto-captions (whisper.cpp), spoken word highlighted.
- Voiceover recording.
- Export 720p to 4K, 24–60 fps, H.264 or HEVC, hardware encoding on Mac.

## Develop

```
npm install            # npm 11: approve ffmpeg-static if asked
npm run dev
npm test               # export engine selftest
npm run build          # .app + .dmg (Mac) / NSIS setup.exe (Windows)
```

Needs Rust (rustup) and, on Mac, Xcode command line tools. Auto-captions need `whisper-cli` (`brew install whisper-cpp`); first use downloads ggml-small (~466 MB).

## Release

Push to `main`: GitHub Actions builds the Mac DMG and Windows installer (see the run's artifacts).
Push a tag `v*`: also creates a draft GitHub Release.

The Mac app is ad-hoc signed, not notarized. First launch: right-click > Open, or System Settings > Privacy & Security > Open Anyway.

## Layout

- `src/` UI (`app.js`), export graph (`graph.js`), shared math (`shared.js`), strings (`i18n.js`), icons (Lucide, generated by `scripts/icons.mjs`).
- `src-tauri/` Rust: ffprobe/ffmpeg/whisper jobs, local media server (`media_server.rs`).
