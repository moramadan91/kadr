جولة في البرنامج

كل حاجة في مكانها.

  1. 01

    التايملاين

    اسحب الفيديوهات والصور والصوت. المسار الأساسي مغناطيسي فمفيش فراغات، والقص بضغطة S.

  2. 02

    المكتبة والكابشن

    استورد ملفاتك، اختار ستايل نص، أو دوس "كابشن تلقائي" ويتفرّغ الكلام بالعربي.

  3. 03

    المعاينة الحية

    شوف الفلاتر والنصوص وانت شغال بسرعة الفيديو الحقيقية، وغيّر المقاس 9:16 أو 16:9 أو 1:1.

  4. 04

    الخصائص

    الحجم والمكان والشفافية وقص الكادر والسرعة والحركة والألوان لكل كليب.

  5. 05

    التصدير

    اختار الجودة لحد 4K والفريمات والكودك، والنتيجة نفس اللي شايفه.

التثبيت

دقيقة وتبدأ.

البرنامج مجاني ومش من متجر أبل أو مايكروسوفت، فالنظام هيسألك أول مرة بس.

ماك

  1. افتح ملف .dmg واسحب ماكتو لـ Applications.
  2. افتح ماكتو. لو ظهرت رسالة إنه مش من مطوّر معروف، دوس Done.
  3. روح System Settings → Privacy & Security وانزل لتحت ودوس Open Anyway.

ماك بمعالج Apple (M1 أو أحدث)، و macOS 12 أو أحدث.

ويندوز

  1. شغّل ملف setup.exe.
  2. لو ظهرت شاشة Windows protected your PC، دوس More info وبعدين Run anyway.
  3. اختار اللغة وكمّل التثبيت.

Windows 10 أو 11، 64-bit.

لو المتصفح وقّف التحميل

المتصفح ساعات بيوقف ملفات البرامج المجانية اللي مش من متجر أبل أو مايكروسوفت، وبالذات لو الحماية في المتصفح مقفولة. الملف نفسه نازل من صفحة ماكتو الرسمية على GitHub، وكمّل التحميل بخطوتين:

ماكتو + Claude Code

اكتب الفكرة، وشوف الفيديو بيتعمل قدامك.

ماكتو فيه سيرفر MCP. بتربطه بـ Claude Code مرة واحدة، وبعدها تكتب البرومبت وClaude يشتغل على التايملاين بتاعك لايف.

جديد · المساعد جوه التطبيق

Claude جوه ماكتو. اكتب، وشوف التايملاين بيتعدّل قدامك.

من غير تيرمنال ولا أوامر ربط: دوس زرار «المساعد» في ماكتو، اكتب اللي عايزه بالعربي، وClaude ينفّذه على التايملاين لايف ويراجع الفريم بنفسه.

  1. ثبّت Claude Code وسجّل دخول بحسابك في Claude.
  2. في ماكتو دوس المساعد فوق.
  3. اكتب طلبك، زي «حط عنوان في أول 3 ثواني»، وتابعه بيتعمل.

محتاج اشتراك Claude Pro أو أعلى. المساعد بيشتغل بحسابك إنت، ومش بيقدر يلمس أي ملفات على جهازك غير المشروع المفتوح.

المساعد
حط عنوان «عرض اليوم» في أول 3 ثواني add items preview تمام، حطيت «عرض اليوم» من 0 لـ 3 ثواني وراجعت الفريم.
عايز تعمل إيه؟

أو اربط ماكتو بـ Claude Code من التيرمنال:

الربط في ٤ خطوات

  1. نزّل ماكتو 1.0.6 أو أحدث. على الماك لازم يكون في Applications.
  2. ثبّت Claude Code وسجّل دخول بحسابك.
  3. افتح التيرمنال وشغّل أمر الربط اللي جنبك، مرة واحدة بس.
  4. افتح جلسة Claude Code جديدة واكتب طلبك، وقول فيه في ماكتو. أول مرة هيستأذن، اختار Allow always.

مش محتاج سلاش ولا تكتب كلمة MCP. لو الأدوات ما ظهرتش، اكتب /mcp في الجلسة واتأكد إن maqto قدامه connected.

أمر الربط

ماك (Terminal)

claude mcp add maqto -s user -- /Applications/Maqto.app/Contents/MacOS/kadr --mcp

ويندوز (PowerShell)

claude mcp add maqto -s user -- "$env:LOCALAPPDATA\Maqto\kadr.exe" --mcp

أسئلة شائعة

قبل ما تسأل.

هو مجاني فعلاً؟

أيوه. من غير اشتراك، ومن غير إعلانات، ومن غير علامة مائية على الفيديو.

محتاج إنترنت؟

لا، المونتاج والتصدير بيشتغلوا من غير إنترنت. الإنترنت محتاجه بس للتحديثات، ولتحميل نموذج الكابشن أول مرة (حوالي 466 ميجا).

بيشتغل على أنهي أجهزة؟

ماك بمعالج Apple (M1 أو أحدث) عليه macOS 12 أو أحدث، وويندوز 10 أو 11 بنظام 64-bit.

التحديثات بتوصل إزاي؟

أول ما تفتح البرنامج بيشوف لو فيه نسخة جديدة ويسألك. لو وافقت بيحمّلها ويقفل ويفتح تاني بالنسخة الجديدة.

فيديوهاتي بتترفع في أي مكان؟

لا. ملفاتك والصوت والتفريغ كله بيحصل على جهازك.
